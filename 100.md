NIP-100
=======

Money Address
-------------

`draft` `optional`

This NIP defines `kind:33277`: an addressable event to describe a `Money Address`.

A `Money Address` describes a method of accepting funds electronically, and consists of a `currency`, `protocol`, and an `address`, as originally described in the [DAP specification](https://github.com/TBD54566975/dap).

These are list events. Multiple `Money Address` events are expected. The use of the `d` tag ensures a single address per currency/protocol pair.

### Author

The `.pubkey` field of these events are treated as the party that can receive the funds.

### Metadata

The following tags, used for structured metadata, are standardized and SHOULD be included. Other tags may be added as necessary.

- `"d"`, the money address type, consisting of a `currency` and `protocol` (e.g. `btc:addr` for a bitcoin on-chain address)
- `"currency"`, the currency, MUST match the currency in the `d` tag
- `"protocol"`, the protocol, MUST match the protocol in the `d` tag
- `"address"`, the protocol-specific address

#### Example Money Address types

- bitcoin on-chain address: `"btc:addr"`
- bitcoin lightning address: `"btc:lnaddr"`
- bitcoin BOLT-12 offer: `"btc:lno"`
- bitcoin BIP-3XX silent payment address: `"btc:spaddr"`
- bitcoin BIP-353 DNS name address: `"btc:dnsaddr"`
- USDC Solana address: `"usdc:sol"`
- USDC Stellar address: `"usdc:xlm"`
- USDC TRON address: `"usdc:tron"`
- AUD payId address: `"aud:payid"`
